# React + Tailwind Starter

A React JSX application powered by Vite and Tailwind CSS v4.

## Requirements

- Node.js 20.19+ (or 22.12+)
- npm

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. Start building in `src/App.jsx`; Tailwind is imported from `src/style.css`.

## Production build

```sh
npm run build
npm run preview
```
